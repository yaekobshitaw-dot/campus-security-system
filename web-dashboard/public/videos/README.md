# Home page background video

The public home page expects a local MP4 at `/videos/campus-security-bg.mp4`.

Important:
- The TikTok page URL provided in the task is not a direct media file URL and should not be used as the HTML video `src`.
- To use the supplied source legally, obtain a direct MP4 from the rights holder or a licensed stock provider, confirm usage rights, and save it here as `campus-security-bg.mp4`.
- Keep the file in this `public/videos` folder so the app can serve it from `/videos/campus-security-bg.mp4` without changing routes or the public site logic.
